# Raahi Mobile

Expo-based React Native app scaffold for the Raahi backend.

## Run

1. `cd mobile`
2. `npm install`
3. Set `EXPO_PUBLIC_API_ROOT` to your backend API, for example `http://10.0.2.2:5000/api`
4. `npm run start`

## Status

This scaffold includes:

- Login
- Role-based routing
- Student live dashboard with ETA and map
- Driver and admin starter screens

Next port candidates:

- Route management
- Bus management
- Student assignment screens
- Push notification setup
- Driver live trip controls
