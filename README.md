# 🚌 Raahi - Real-Time School Bus Tracking System

> A comprehensive full-stack solution for real-time school bus tracking, emergency detection, and management

## 🚀 Quick Start

### Prerequisites
- Node.js 16+
- MongoDB instance
- Git

### Installation
```bash
# Clone repository
git clone <repo-url>
cd raahi

# Backend setup
cd backend && npm install
cp .env.example .env
npm run dev

# Frontend setup (new terminal)
cd frontend && npm install
npm run dev

# Visit http://localhost:5173
```

### Default Credentials
```
Username: admin
Password: admin123
```

## 🎯 Key Features

- ✅ Real-time GPS tracking with live location updates
- ✅ Automatic emergency detection (speed drops, falls, loud noise)
- ✅ Manual SOS with nearby hospital/police lookup
- ✅ Multi-role access control (Admin, Driver, Student)
- ✅ Route & stop management with ETA calculation
- ✅ Admin dashboard with real-time SOS alerts
- ✅ Mobile app (React Native/Expo)
- ✅ Push notifications via Socket.io

## 🛠️ Tech Stack

**Backend:** Node.js • Express.js • MongoDB • Socket.io  
**Frontend:** React • Vite • Tailwind • Leaflet  
**Mobile:** React Native • Expo
